About ColorVerse

ColorVerse is a college project designed to explore the connection between color, psychology and design using simple web technologies.

Project Overview

This project acts as a mini color encyclopedia. It combines color psychology, color theory and interactive tools to help users make better color decisions for branding, UI and creative work.

Objectives

  • Present color psychology in a clear, visual way.
  • Teach core color theory concepts using an interactive wheel.
  • Offer practical palettes for real-world design use cases.
  • Include a hands-on tool using the HTML canvas element.
  • Structure data with JSON for easy expansion.

Technologies Used

  • Python 3 & Flask – backend REST API server, color algorithms and system routing.
  • Python qrcode & Pillow (PIL) – dynamic color-matched QR code image generation.
  • HTML & CSS – semantic layouts, dark theme glassmorphism, responsive UI.
  • JavaScript – DOM styling, hex algorithms, interactive canvas and event handlers.
  • JSON – data source for colors, palettes and theory models.

Key Features

  • Color grid with psychology, usage tips and search filters.
  • Curated palette collections with preview mockups.
  • Interactive color theory wheel and harmony schemes.
  • Color Flipper with Hex generation, Math.random() & dynamic DOM styling.
  • Python-powered Color QR Code Generator for mobile sharing & export.
  • ChromaTyper Speed Tester with color modes, time deltas & accuracy algorithms.
  • Color canvas & mixer for hands-on drawing.

Learning Outcomes

Building ColorVerse shows how front-end technologies can turn abstract design concepts into interactive educational tools. It also demonstrates data-driven UI by loading content from JSON files instead of hard-coding everything.
