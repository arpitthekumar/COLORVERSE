📐 Time Deltas & Accuracy Calculation Algorithms

This typing test runs real-time mathematical algorithms to compute typing kinetics: 

// 1. Time Delta Calculation (Precision Timer)
const timeDeltaSeconds = (performance.now() - startTime) / 1000;
const elapsedMinutes = timeDeltaSeconds / 60;

// 2. Net Words Per Minute (Standard 5 chars = 1 word)
const netWPM = Math.max(0, Math.round(((correctChars / 5) - errorCount) / elapsedMinutes));

// 3. Accuracy Percentage Formula
const accuracy = Math.round((correctChars / totalCharactersTyped) * 100);
